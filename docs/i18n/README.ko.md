# Polylode

[English](../../README.md) · [繁體中文](README.zh-TW.md) · [简体中文](README.zh-CN.md) · [日本語](README.ja.md) · **한국어** · [Español](README.es.md) · [Français](README.fr.md) · [Deutsch](README.de.md)

**단계별 사용 안내(영어·번체 중국어):** [https://je-chen.github.io/Polylode/](https://je-chen.github.io/Polylode/)

Polylode는 설치한 게임에서 캐릭터 모델을 캐내어——광맥(*lode*)에서 폴리곤(*poly*gon)을——텍스처와 리그가 있는, 어디서나 열 수 있는 파일로
기록합니다: glTF(`.glb`), FBX, Blender(`.blend`). 창, 마우스로 돌려 볼 수 있는 미리보기, 모델 뷰어를 갖춘 Windows 데스크톱 프로그램입니다.

| 게임 | 읽는 것 | 비고 |
|---|---|---|
| 명일방주: 엔드필드 | 모든 플레이어블 캐릭터의 프리팹 | 첫 스캔에서 설치로부터 자산 대응표를 만들고(나누어 검증, 중단 후 재개 가능) 게임 업데이트 후 다시 만듦 |
| 소녀전선 2: 망명 | 모든 플레이어블 캐릭터의 의상 | 자체 스킨 메시와 완전한 인간형 골격이 있는 루트만 나열(펫, 소품, 빈 변형 제외). 부품을 바꿀 수 있는 의상은 게임이 기본으로 입히는 조합으로 보이고, 다른 버전과 낮은 디테일 단계는 FBX와 .blend에 숨겨 둡니다(.glb에는 보이는 부분만 넣습니다. Blender와 대부분의 뷰어가 glTF의 숨김 표시를 무시하기 때문) |
| 명조 | 모든 플레이어블 캐릭터의 표시 모델 | AES 키 파일 필요(`tools/wuwa_cli`로 빌드한 게임 파일 리더는 포함됨). 재질 구역(머리카락, 얼굴, 상체…)마다 별도 부품 |
| 기존 변환물 | `*_Converted` 폴더의 완성 모델 | 파일마다 SHA-256을 확인한 뒤 복사 |

## 기능

- **스캔, 체크, 내보내기.** 게임마다 페이지가 있어 설치를 스캔하고, 검색하고, 모델을 체크해 대기열로 내보냅니다. 스캔과 내보내기는 각각 별도
  프로세스에서 실행되므로 변환기가 실패해도 창이 멈추지 않습니다.
- **설치를 자동으로 찾기.** 스캔 전에 Steam 라이브러리에서 찾은 설치를 후보로 보여 줍니다. 게임 폴더, 그 상위 폴더, 데이터 안쪽 중 아무것이나 고를 수 있습니다.
- **세 가지 형식, 그중 둘은 Blender 불필요.** `.glb`와 FBX는 Polylode가 직접 씁니다(골격, 스킨 메시, 셰이프 키, 내장 텍스처, 투명).
  `.blend`에는 Blender가 필요합니다. Blender를 지정하면 모든 파일을 Blender에서 다시 읽어 확인합니다.
- **게임 그대로의 재질.** 컷아웃, 반투명, 아이섀도 오버레이, 눈 하이라이트 층을 각 게임 셰이더에서 읽은 규칙대로 씁니다. glTF/FBX가 그릴 수 없는
  층은 그 효과를 아래 텍스처에 구워 넣고, `.blend`는 실제 층으로 남깁니다. 명조의 컷아웃 커버리지는 게임이 컴파일한 셰이더를 직접 실행해 구하고, 시차 털은 털 가닥 층으로 만듭니다. 엔드필드의 이펙트 재질(날개, 빛)은 게임이 컴파일한 셰이더로 실행해 굽고, 발광 맵은 발광으로 씁니다. 그릴 수 없는 재질은 회색으로 그리지 않고 보이지 않게 한 뒤 기록에 남깁니다.
- **내보내기 전 미리보기.** 행을 고르고 「미리보기」(또는 더블클릭): 모델을 `.glb`로 변환해 캐시에 두고 목록 옆에 보여 줍니다——왼쪽 드래그 회전,
  오른쪽 드래그 이동, 휠 확대·축소. 프로그램이나 게임 파일을 업데이트한 뒤에는 「**다시 변환**」으로 새로 만듭니다.
- **모델 뷰어.** 출력 폴더의 모든 모델을 나열하고 어떤 `.glb`, `.gltf`, `.fbx`, `.obj`든 엽니다(끌어다 놓기, 선택, 또는 `Polylode.exe <파일>`.
  「연결 프로그램」으로 지정 가능): 정면·후면·측면·위쪽 시점, 와이어프레임, 밝은/어두운 배경, 조명 세기, glTF 내용. 목록의 모델은 휴지통으로 삭제할 수 있습니다.
- **GitHub Pages를 통해 Discord에 공유.** Discord는 3D 모델을 보여 주지 않으므로, 모델 뷰어의 **GitHub Pages에 공유…** 가
  표시 중인 `.glb`를 내 GitHub Pages 사이트에 브라우저에서 돌려 볼 수 있는 페이지로 쓰고, 푸시한 뒤 주소를 복사합니다.
  Discord에 붙여 넣으면 모델 그림이 있는 카드로 보입니다.
- **다섯 가지 언어.** English, 繁體中文, 简体中文, 日本語, 한국어. 기본은 시스템을 따르며 「설정」에서 고르면 바로 바뀝니다.

## 다운로드

[Releases](https://github.com/JE-Chen/Polylode/releases)에서 최신 `Polylode-<버전>-windows-x64.zip`을 받아 아무 곳에나 풀고 `Polylode.exe`를
실행합니다. 필요한 것은 모두 들어 있습니다: AnimeStudio(엔드필드용), 명조 리더, .NET 10 런타임, glTF 가져오기 모듈, GPU 드라이버가 없는 컴퓨터용 소프트웨어 OpenGL.

요구 사항: Windows 10 또는 11, 64비트. `.blend`에만 Blender 4.x 또는 5.x가 필요합니다.

## 사용 안내

### 1. 처음 실행

릴리스를 아무 곳에나 풀고 `Polylode.exe`를 실행합니다. 화면은 Windows 언어를 따르며, 「**설정 → 언어**」에서 고르면 바로 바뀝니다.
설정은 입력하는 대로 저장되고 모든 캐시와 함께 `%LOCALAPPDATA%\Polylode`에 있습니다. IslandLife의 일부였을 때 내보내기 도구를
썼다면, 처음 실행할 때 그 설정, 엔드필드 자산 대응표, GF2 색인과 저장소를 옮겨 오므로 다시 만들 필요가 없습니다.

### 2. 설정

- **출력 폴더**——내보낼 위치. 모델마다 폴더를 만듭니다: `<출력>\<게임>\<모델 ID>\`.
- **내보내기 형식**——`.glb`, FBX, `.blend`. 여러 개를 고를 수 있습니다.
- **Blender 실행 파일**——선택 사항. `.blend`에만 필요하며, 지정하면 모든 `.glb`와 FBX도 Blender에서 다시 읽어 확인합니다.
- **설치 폴더**——비워 둬도 됩니다. 스캔할 때 하나씩 묻고 Steam 라이브러리에서 찾은 것도 보여 줍니다. 게임 폴더, 그 상위 폴더,
  데이터 안쪽 중 아무것이나 됩니다. 존재하는 경로에는 ✓가 붙습니다.
- **도구**——비워 두면 프로그램에 들어 있는 것을 씁니다: AnimeStudio(엔드필드), 명조 리더, .NET 런타임. 명조에는 **AES 키 파일**
  (사용 중인 버전의 `mainKey`와 `dynamicKeys`가 있는 JSON)도 필요합니다. 파일이 암호화되어 있고 키는 여러분의 것이라 프로그램에
  넣을 수 없습니다. 첫 미리보기나 내보내기 전에 프로그램 옆, 데이터 폴더, 설치 폴더와 그 상위 폴더, 다운로드, 문서, 바탕 화면에서 이미 가진 키 파일을 찾고, 없을 때만 묻습니다.

### 3. 스캔

게임 페이지를 열고 「**설치 스캔**」을 누릅니다. 상태 줄 아래 막대가 현재 단계를 보여 주고, 셀 수 있는 단계는 진행률을 표시합니다.
첫 스캔에 드는 시간:

- **명일방주: 엔드필드**는 설치에서 자산 대응표를 만듭니다(수십 분, 나누어 진행). 중간에 프로그램을 닫아도 헛수고가 아니며
  다음 스캔이 이어서 진행합니다.
- **소녀전선 2**는 bundle 색인을 만들고(수 분) 어떤 루트가 캐릭터 모델인지 확인합니다.
- **명조**는 아카이브에서 캐릭터 표를 읽습니다.

이후 스캔은 게임이 업데이트될 때까지 재사용합니다. 업데이트 후에는 다시 스캔하세요. GF2 설치가 스캔 뒤에 바뀌었으면 미리보기나
내보내기가 알려 줍니다.

### 4. 미리보기

행을 고르고——검색창으로 캐릭터, 의상, ID를 걸러낼 수 있습니다——「**미리보기**」를 누르거나 더블클릭합니다. 모델의 첫 미리보기는
먼저 변환합니다(몇 초~1분, 전용 진행 막대). 이후에는 그 행을 고르면 캐시에서 바로 보여 줍니다. 화면에서 **왼쪽 드래그**는 회전,
**오른쪽 드래그**는 이동, **휠**은 확대·축소입니다. 불러올 때마다 모델 전체가 가운데에 맞춰집니다.

미리보기는 처음 만든 그대로 남습니다. 「**다시 변환**」은 고른 행을 새로 변환하고——Polylode나 게임 업데이트 후——새것이
완성되면 캐시를 바꿉니다. 그때까지는 이전 것이 남습니다.

### 5. 내보내기

모델을 체크하고(「**모두 선택**」「**모두 해제**」는 검색으로 보이는 행에만 적용) 「**체크한 모델 내보내기**」를 누릅니다. 아래
대기열이 하나씩 처리합니다: ⏳ 대기, ▶ 진행 중, ✓ 완료, ✗ 실패——이유는 옆 로그에 나옵니다. 대기열 아래 막대는 모델 수를,
그 아래 막대는 쓰고 있는 모델의 단계를 보여 줍니다. 내보내는 중에 창을 닫으면 먼저 묻습니다.

### 6. 모델 뷰어

출력 폴더의 모델을 최신순으로 나열합니다. 「**파일 열기…**」, 창에 끌어다 놓기, 또는 `Polylode.exe <파일>`(「연결 프로그램」으로
지정 가능)로 어떤 `.glb`, `.gltf`, `.fbx`, `.obj`든 볼 수 있습니다. 「**정면**」「**후면**」「**왼쪽**」「**오른쪽**」「**위**」로
방향을 바꾸고, 「**와이어프레임**」, 배경 버튼, 「**조명**」으로 표시를 바꿉니다. 오른쪽 패널은 glTF 내용——메시, 정점, 본, 셰이프
키, 각 재질의 혼합 방식——을 나열하고, 예전 규칙으로 써서 다시 내보내야 할 파일을 표시합니다. 「**삭제…**」는 모델과 같은 이름의
파일, 텍스처 폴더를 휴지통으로 옮깁니다.

### 7. GitHub Pages에 공유(Discord용)

Discord는 3D 모델을 보여 주지 못하고, 올린 `.glb`는 내려받기 파일일 뿐입니다. Polylode는 모델을 내 GitHub 계정의 GitHub Pages 사이트에
있는 페이지 하나로 공유합니다. 페이지는 어느 브라우저에서나 모델을 돌려 볼 수 있고, 주소는 Discord에서 모델 그림이 있는 카드로 보입니다.
따로 설치할 것은 없습니다(Git도 clone도 필요 없음).

1. 모델 뷰어에서 `.glb`를 열고 **GitHub Pages에 공유…** 를 누릅니다. 모델이 공개될 주소를 알려 주고 확인한 뒤 진행합니다.
2. 처음에는 브라우저에서 GitHub 로그인 페이지를 열고 짧은 코드(복사됨)를 보여 줍니다. 코드를 입력하고 Polylode를 승인하세요.
   요청하는 권한은 `public_repo`(공개 저장소 만들기와 쓰기)뿐이며, 승인은 이 컴퓨터에만 Windows 사용자용으로 암호화해 저장합니다.
   **설정 → GitHub 계정 → 로그아웃**으로 지울 수 있고, GitHub의 Settings → Applications에서 취소할 수 있습니다.
3. 계정에 공개 저장소 `polylode-models`를 만들고(처음 한 번), `models/<이름>/`(모델, 미리보기처럼 그린 1200×630 카드 그림, 페이지)와
   사이트의 모델 목록을 커밋 하나로 올립니다.
4. 주소가 복사됩니다: `https://<계정>.github.io/polylode-models/models/<이름>/`. 처음에 이 저장소의 Pages가 아직 꺼져 있으면 메시지에
   **Pages 설정 열기**가 나옵니다. **Deploy from a branch**, `main`, `/ (root)`를 고르고 Save(한 번만). (프로그램에서 켜려면 모든 비공개
   저장소에 대한 권한이 필요해서 요청하지 않습니다.)
5. GitHub Pages는 보통 1~2분 뒤 갱신됩니다. 그다음 Discord에 붙여 넣으면 됩니다.

이미 Pages 사이트가 있다면 **설정 → GitHub Pages 사이트 폴더**에 그 로컬 clone을 지정하세요. 그러면 공유가 그곳에 커밋하고 Git으로 푸시합니다.

`.glb`만, 최대 100 MB(GitHub 파일당 한도)까지 공유할 수 있고, 같은 모델을 다시 공유하면 페이지가 바뀝니다. 공유한 것은 모두
공개됩니다. 모델은 게임에서 나온 것이므로 공유해도 되는지 확인하세요. 이 프로그램 자신의 폴더는 사이트로 쓸 수 없습니다.

### 문제 해결

- **스캔, 미리보기, 내보내기 전에 설명이나 파일 선택 창이 열림**——변환에 꼭 필요한 도구가 설정되지 않았고 찾는 곳에도 없습니다. 명조라면 AES 키 파일입니다. 창이 무엇인지 설명하니 키 파일을 고르거나 키(`0x`와 16진수 64자리)를 붙여 넣으면 키 파일로 저장합니다. 어느 쪽이든 이후 기억합니다.
- 로그에 **「…이(가) 설정되지 않았습니다」「…이(가) 없습니다」**——「**설정**」에서 그 경로를 고치세요.
- **「이 파일의 크기를 잴 수 없어」**——뷰어가 파일의 범위를 읽지 못했습니다(예: FBX 7.5 파일). 시점이 원점에 있으니 휠로
  확대·축소하세요.
- **`.blend`가 써지지 않음**——「**설정**」에서 Blender 실행 파일을 지정하세요.
- **공유할 때 「git push 실패」** —— Git이 사이트 저장소에 푸시하지 못합니다. Git에서 GitHub에 로그인하고(예: Git Credential Manager),
  그 폴더에서 직접 푸시할 수 있는지 확인하세요. **「사이트 폴더의 origin이 GitHub 저장소가 아닙니다」** —— 폴더는 GitHub 저장소의 clone이어야 합니다.
- **그 밖의 실패**——아래 로그에 스캔이나 내보내기가 출력한 모든 줄이 남아 있습니다.

## 소스에서 빌드

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements-dev.txt
.venv\Scripts\python -m polylode.extractor          # 소스에서 창 실행
.venv\Scripts\python -m pytest tests                # 테스트
.venv\Scripts\python build.py --dotnet <dotnet 폴더>   # dist\Polylode\Polylode.exe, 이어서 자체 점검
```

빌드는 Nuitka로 컴파일하고(C 컴파일러 필요: Visual Studio), AnimeStudio, .NET 10 런타임(`--dotnet`, 기본값 `DOTNET_ROOT`), 소프트웨어 OpenGL을
프로그램 옆에 두고 `Polylode.exe --selftest`를 실행합니다. 모든 변환 모듈, 미리보기 QML, 실제 `.glb`를 불러오며 하나라도 없으면 빌드가 실패합니다.

프로그램에 들어 있는 명조 리더는 `tools/wuwa_cli/build.ps1`로 빌드하고(그 `README.md` 참고) `--wuwa-reader`로 빌드에 넘깁니다. 워크플로가 둘 다 합니다. `tools/screenshots.py`는 창 자체의 스캔과 미리보기로 위 스크린샷을 다시 찍습니다.

## CI/CD

- **CI**(`.github/workflows/ci.yml`)——`main`과 `dev`로의 푸시와 PR마다 Windows에서 린트, 테스트, 자체 점검을 실행합니다.
- **Release**(`.github/workflows/release.yml`)——`main`으로 푸시할 때마다 테스트, Nuitka 빌드와 패키지판 자체 점검을 거쳐 압축한 프로그램을 GitHub Release로 게시합니다.

개발은 `dev`, `main`이 릴리스 버전입니다.
