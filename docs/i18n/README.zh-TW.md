# Polylode

[English](../../README.md) · **繁體中文** · [简体中文](README.zh-CN.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Español](README.es.md) · [Français](README.fr.md) · [Deutsch](README.de.md)

**一步一步的使用教學：** [https://je-chen.github.io/Polylode/zh-TW/](https://je-chen.github.io/Polylode/zh-TW/)

Polylode 從你安裝的遊戲裡把角色模型挖出來——從礦脈（*lode*）裡挖出多邊形（*poly*gon）——寫成帶貼圖、帶骨架、到處都能開的檔案：
glTF（`.glb`）、FBX 與 Blender（`.blend`）。它是 Windows 桌面程式，有視窗、能用滑鼠轉動的預覽，以及模型檢視器。

| 遊戲 | 讀什麼 | 說明 |
|---|---|---|
| 明日方舟：終末地 | 每個可玩角色的預製物 | 第一次掃描會從你的安裝建資產對照表（分批核對、可中斷續跑），遊戲更新後重建 |
| 少女前線 2：追放 | 每個可玩角色的各套衣裝 | 只列出有自己蒙皮網格與完整人形骨架的根節點（不含寵物、道具與空的變體）。有可替換部件的衣裝照遊戲預設的穿法顯示，其他版本與較低細節層級留在 FBX 與 .blend 裡、設為隱藏（.glb 只放顯示的部分：Blender 與多數檢視器不理會 glTF 的隱藏標記） |
| 鳴潮 | 每個可玩角色的顯示模型 | 需要你的 AES 金鑰檔；遊戲檔讀取器（由 `tools/wuwa_cli` 建出）已隨程式附上；每個材質段落（頭髮、臉、上身…）各自是一個部件 |
| 既有轉出物 | `*_Converted` 資料夾裡做好的模型 | 逐檔核對 SHA-256 後複製出來 |

## 功能

- **掃描、勾選、匯出。** 每個遊戲一頁：掃描安裝、搜尋、勾選模型，排進佇列匯出。每次掃描與匯出都在自己的行程裡跑，轉換器出錯不會拖垮視窗。
- **自動找安裝。** 掃描前會列出在 Steam 遊戲庫找到的安裝；選遊戲資料夾、它的上一層或資料夾裡面都可以。
- **三種格式，其中兩種不需要 Blender。** `.glb` 與 FBX 由 Polylode 自己寫（骨架、蒙皮網格、形狀鍵、內嵌貼圖、透明）；`.blend` 需要 Blender。
  設定了 Blender 時，每個檔案都會在 Blender 讀回核對。
- **材質照遊戲的畫法。** 裁切、半透明、眼影疊層與眼睛高光層都照從各遊戲 shader 讀出的規則寫出；glTF／FBX 畫不出的疊層，效果會烘進底下的貼圖，
  `.blend` 保留真正的分層。鳴潮的裁切覆蓋率由執行遊戲自己編譯好的 shader 得出，視差毛髮做成一層層毛絲。終末地的特效材質（翅膀、光效）用遊戲編譯好的 shader 執行後烘焙，發光貼圖寫成發光；畫不出來的材質不會畫成灰白，而是設為不可見並記錄原因。
- **匯出前預覽。** 選一列按「預覽」（或雙擊）：模型轉成 `.glb` 放進快取、顯示在清單旁——左鍵拖曳旋轉、右鍵平移、滾輪縮放。程式或遊戲檔更新後，按「**重新轉換**」重做。
- **模型檢視器。** 列出輸出資料夾裡的所有模型，也能開任何 `.glb`、`.gltf`、`.fbx`、`.obj`（拖進來、選檔，或用 `Polylode.exe <檔案>`，
  可以設成「開啟檔案」的程式）：正面、背面、側面、上方視角、線框、深淺背景、燈光強度，以及 glTF 的內容。清單裡的模型可以刪到資源回收筒。
- **透過 GitHub Pages 分享到 Discord。** Discord 不能顯示 3D 模型，所以模型檢視器的 **分享到 GitHub Pages…** 會把顯示中的
  `.glb` 寫進你自己的 GitHub Pages 網站，做成一個在瀏覽器裡就能轉動模型的網頁，推送後複製網址；網址貼到 Discord 會顯示成帶模型圖片的卡片。
- **五種語言。** English、繁體中文、简体中文、日本語、한국어；預設跟隨系統，可在「設定」切換，立即生效。

## 下載

到 [Releases](https://github.com/JE-Chen/Polylode/releases) 下載最新的 `Polylode-<版本>-windows-x64.zip`，解壓到任何地方，執行 `Polylode.exe`。
需要的東西都已經附上：AnimeStudio（終末地用）、鳴潮讀取器、.NET 10 執行環境、glTF 匯入器，以及給沒有顯示卡驅動的電腦用的軟體 OpenGL。

需求：Windows 10 或 11，64 位元。只有 `.blend` 需要 Blender 4.x 或 5.x。

## 使用說明

### 1. 第一次啟動

把 Release 解壓到任何地方，執行 `Polylode.exe`。介面跟隨 Windows 的語言；到「**設定 → 語言**」可以換，立即生效。設定邊打邊存，
和所有快取一起放在 `%LOCALAPPDATA%\Polylode`。如果你在它還是 IslandLife 一部分時用過匯出工具，第一次啟動會把它的設定、
終末地資產對照表、GF2 索引與倉庫搬過來，不用重建。

### 2. 設定

- **輸出資料夾**——匯出的位置，每個模型一個資料夾：`<輸出>\<遊戲>\<模型編號>\`。
- **匯出格式**——`.glb`、FBX、`.blend`，可以複選。
- **Blender 執行檔**——選填。只有 `.blend` 需要；設定了之後，每個 `.glb` 與 FBX 也會在 Blender 讀回核對。
- **安裝資料夾**——可以留空：掃描時會逐一詢問，並列出在 Steam 遊戲庫找到的。選遊戲資料夾、它的上一層或資料夾裡面都可以。
  存在的路徑旁邊會打 ✓。
- **工具**——留空就用程式內建的：AnimeStudio（終末地）、鳴潮讀取器與 .NET 執行環境。鳴潮另外需要你的 **AES 金鑰檔**
  （含你那個版本 `mainKey` 與 `dynamicKeys` 的 JSON）：它的檔案是加密的，金鑰屬於你自己，程式不能附帶。第一次預覽或匯出前，會先在程式旁、它的資料夾、安裝資料夾與上一層、下載、文件、桌面找你已經有的金鑰檔，找不到才問。

### 3. 掃描

打開遊戲頁，按「**掃描安裝**」。狀態列下方的進度條會寫出目前的步驟，能計數的就顯示進度。第一次掃描要花的時間：

- **明日方舟：終末地**從安裝建資產對照表：幾十分鐘，分批進行。中途關掉程式不會白做，下次掃描接著做。
- **少女前線 2**建 bundle 索引（幾分鐘），並檢查哪些根節點是角色模型。
- **鳴潮**從封存檔讀出角色表。

之後的掃描在遊戲更新前都沿用。遊戲更新後請重新掃描；GF2 的安裝在掃描後有變動時，預覽或匯出會提醒你。

### 4. 預覽

選一列——搜尋框可以依角色、衣裝或編號過濾——按「**預覽**」或雙擊。一個模型第一次預覽時會先轉換（幾秒到一分鐘，有自己的
進度條）；之後選那一列就直接從快取顯示。在預覽裡：**左鍵拖曳**旋轉、**右鍵拖曳**平移、**滾輪**縮放。每個模型載入時都會
自動框住整個模型並置中。

預覽會保持第一次做出來的樣子。「**重新轉換**」會重新轉換選取的那一列——更新 Polylode 或遊戲之後用——新的做好才取代快取，
在那之前保留原本的。

### 5. 匯出

勾選模型（「**全選**」「**全不選**」只作用在搜尋後顯示的列），按「**匯出勾選的模型**」。下方的佇列一次做一個：⏳ 等待、
▶ 進行中、✓ 完成、✗ 失敗——旁邊的記錄寫出原因。佇列下的進度條算模型數，再下面一條是正在寫出的模型目前的步驟。匯出進行中
關閉視窗會先詢問。

### 6. 模型檢視器

列出輸出資料夾裡的模型，最新的在前。「**開啟檔案…**」、把檔案拖進視窗，或用 `Polylode.exe <檔案>` 啟動（可以設成
「開啟檔案」的程式），就能看任何 `.glb`、`.gltf`、`.fbx`、`.obj`。「**正面**」「**背面**」「**左側**」「**右側**」「**上方**」
轉動模型；「**線框**」、背景按鈕與「**光**」改變畫法。右側面板列出 glTF 的內容——網格、頂點、骨頭、形狀鍵與每個材質的混合
方式——並標出照舊規則寫出、應重新匯出的檔案。「**刪除…**」把模型、同名的檔案與貼圖資料夾移到資源回收筒。

### 7. 分享到 GitHub Pages（給 Discord 用）

Discord 不能顯示 3D 模型，貼上去的 `.glb` 只是一個下載檔。Polylode 把模型分享成你自己 GitHub 帳號裡 GitHub Pages 網站上的一個網頁：
網頁在任何瀏覽器裡都能轉動模型，網址貼到 Discord 會顯示成帶模型圖片的卡片。不需要另外安裝任何東西：不用 Git，也不用 clone。

1. 在模型檢視器開啟一個 `.glb`，按 **分享到 GitHub Pages…**。它會先說模型會公開在哪個網址，問過你才繼續。
2. 第一次會在瀏覽器開啟 GitHub 的登入頁，並顯示一組短代碼（已複製）：輸入代碼並授權 Polylode。它只要求 `public_repo`
   （建立與寫入公開倉庫），授權只存在這台電腦，並以你的 Windows 使用者加密保存。**設定 → GitHub 帳號 → 登出** 會把它刪掉；
   也可以在 GitHub 的 Settings → Applications 撤銷。
3. 它會在你的帳號建立公開倉庫 `polylode-models`（只有第一次），然後把 `models/<名稱>/`（模型、照預覽畫出的 1200×630 卡片圖、網頁）
   與網站的模型清單，以一個 commit 上傳。
4. 網址已複製：`https://<帳號>.github.io/polylode-models/models/<名稱>/`。第一次如果這個倉庫的 Pages 還沒開啟，訊息會有
   **開啟 Pages 設定**：選 **Deploy from a branch**、`main`、`/ (root)`，按 Save，只需要做一次。（從程式直接開啟需要存取你所有私人倉庫的權限，程式不會要這個權限。）
5. GitHub Pages 通常一兩分鐘後更新，之後把網址貼到 Discord 即可。

**姿勢。** 終末地角色匯出的 `.glb` 會帶著遊戲角色介面上擺的姿勢（遊戲裡會循環播放的 `ui` 動作，第一次從安裝解碼，大約半分鐘）。
分享的網頁有 **Pose** 選單可以切換，卡片圖顯示第一個姿勢。**設定 → 姿勢** 可以關掉；預覽一律不含姿勢。少女前線 2 與鳴潮的角色目前還沒有姿勢。

已經有自己的 Pages 網站？把 **設定 → GitHub Pages 網站資料夾** 指到它在本機的 clone，分享就會改成提交到那裡、用 Git 推送。

只能分享 `.glb`，最大 100 MB（GitHub 的單檔上限）；同一個模型再分享一次會換掉它的網頁。分享出去的東西都是公開的：
模型來自遊戲，請自行確認可以分享。本程式自己的資料夾不能當網站。

### 疑難排解

- **掃描、預覽或匯出前跳出說明或選檔視窗**——轉換少了一個非有不可的工具，程式會找的地方也沒有。鳴潮的話就是 AES 金鑰檔：視窗會說明它是什麼；選你的金鑰檔，或貼上金鑰（`0x` 加 64 位十六進位），程式會存成金鑰檔。之後都會記住。
- 記錄出現 **「…還沒有設定」或「…不存在」**——到「**設定**」修正那個路徑。
- **「量不到這個檔案的大小」**——檢視器讀不出檔案的範圍（例如 FBX 7.5 的檔案）；視角放在原點，用滾輪縮放。
- **沒有寫出 `.blend`**——到「**設定**」指定 Blender 執行檔。
- **分享時出現「git push 失敗」** —— Git 推送不到網站的倉庫：在 Git 登入 GitHub（例如 Git Credential Manager），並確認自己能從那個資料夾推送。
  **「網站資料夾的 origin 不是 GitHub 倉庫」** —— 那個資料夾要是某個 GitHub 倉庫的 clone。
- **其他失敗**——下方的記錄保留了掃描或匯出印出的每一行。

## 從原始碼建置

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements-dev.txt
.venv\Scripts\python -m polylode.extractor          # 從原始碼開視窗
.venv\Scripts\python -m pytest tests                # 測試
.venv\Scripts\python build.py --dotnet <dotnet 資料夾>   # dist\Polylode\Polylode.exe，接著跑它的自檢
```

建置用 Nuitka 編譯（需要 C 編譯器：Visual Studio 的），把 AnimeStudio、.NET 10 執行環境（`--dotnet`，預設 `DOTNET_ROOT`）與軟體 OpenGL
放到程式旁，再執行 `Polylode.exe --selftest`：它會載入每個轉換器、預覽的 QML 與一個真的 `.glb`，少了任何一樣建置就失敗。

程式附帶的鳴潮讀取器由 `tools/wuwa_cli/build.ps1` 建出（見它的 `README.md`），再用 `--wuwa-reader` 交給建置；兩個工作流程都會做這兩步。`tools/screenshots.py` 會透過視窗自己的掃描與預覽重拍上面的截圖。

## CI/CD

- **CI**（`.github/workflows/ci.yml`）——每次推送與 PR 到 `main`、`dev`：在 Windows 上跑程式碼檢查、測試與自檢。
- **Release**（`.github/workflows/release.yml`）——每次推送到 `main`：測試、Nuitka 建置與打包版自檢，並把壓縮好的程式發佈成 GitHub Release。

開發在 `dev`，`main` 是發佈的版本。

## 結構

```
polylode/extractor/      視窗、掃描、工作、預覽、檢視器、語言
polylode/endfield/       明日方舟：終末地——資產對照表、轉換、FBX 場景
polylode/gf2/            少女前線 2——bundle、可玩名冊、轉換、眼睛疊層烘焙
polylode/wuthering_waves/  鳴潮——角色表、顯示模型組合
polylode/interchange/    glTF 與 FBX 寫出器（不需要 Blender）
tools/                   Blender 腳本、圖示、FBX SDK 檢查、鳴潮讀取器原始碼、AnimeStudio
tests/                   pytest
docs/                    截圖、工具說明、架構、待辦、README 的翻譯
build.py, main.py        打包的程式
```

Polylode 的程式碼採 GNU LGPL 2.1（`LICENSE`）；附帶的 AnimeStudio 是 MIT（`tools/AnimeStudio/LICENSE`）。Polylode 不含任何遊戲內容：
它轉換的是你自己電腦上安裝的檔案，寫出的東西也留在你的電腦上。截圖裡的模型是從作者自己的安裝轉出的。只用在你擁有的遊戲上，並遵守它們的條款。
