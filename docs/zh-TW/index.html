Polylode 使用教學

Polylode 會從你電腦上已安裝的遊戲讀出角色模型，寫成帶貼圖與骨架的 glTF（.glb）、FBX 與 Blender（.blend）檔。 目前支援《明日方舟：終末地》、《少女前線 2：追放》、《鳴潮》，以及已轉換好的模型。下面照實際使用的順序一步一步說明。

1. 下載與啟動

1下載

到 Releases 下載最新的 Polylode-<版本>-windows-x64.zip。

2解壓縮

解壓到任何資料夾都可以，例如 D:\Tools\Polylode。不需要安裝，裡面已經附上需要的工具：AnimeStudio（終末地用）、鳴潮讀取器、.NET 10 執行環境， 以及給沒有顯示卡驅動的電腦用的軟體 OpenGL。

3執行 Polylode.exe

視窗語言預設跟隨 Windows；要換的話到 設定 → 語言，切換後立即生效（English、繁體中文、简体中文、日本語、한국어）。

需求：Windows 10 或 11（64 位元）。只有要輸出 .blend 時才需要 Blender 4.x 或 5.x。設定與所有快取都放在 %LOCALAPPDATA%\Polylode。

2. 基本設定

打開 設定 頁。設定在輸入時就會存下來，不必另外按儲存。

1輸出資料夾

匯出的檔案放這裡，每個模型一個資料夾：<輸出資料夾>\<遊戲>\<模型編號>\。

2匯出格式

勾選要的格式：.glb、FBX、.blend，可以多選。.glb 與 FBX 由 Polylode 自己寫，不需要 Blender。

3Blender 執行檔（選填）

只有要 .blend 時才需要，指到 blender.exe。設定之後，每個 .glb 與 FBX 也會在 Blender 裡讀回核對一次，確認檔案正確。

4安裝資料夾與工具

可以先留空。第一次掃描時程式會詢問，並列出它在 Steam 遊戲庫裡找到的安裝；選遊戲本身的資料夾、上一層或裡面的資料夾都可以，旁邊打勾表示路徑存在。 工具欄位留空就會用程式附帶的版本。

3. 各遊戲的準備

遊戲需要準備第一次掃描
明日方舟：終末地只要安裝資料夾從安裝建立資產對照表，要數十分鐘，分批進行；中途關掉不會損失，下次掃描接著做。
少女前線 2：追放只要安裝資料夾建立 bundle 索引（幾分鐘），並檢查哪些根節點是角色模型。
鳴潮安裝資料夾＋你自己的 AES 金鑰檔從封存檔讀出角色表。

鳴潮的 AES 金鑰

鳴潮的檔案是加密的，需要符合你遊戲版本的金鑰；程式不能附帶它。金鑰檔是一個 JSON，含 mainKey 與 dynamicKeys。

1放到程式找得到的地方

第一次預覽或匯出前，程式會在這些地方找已有的金鑰檔：程式旁邊、它的資料夾、遊戲安裝資料夾與上一層、下載、文件、桌面。找到就直接用。

2找不到時會跳出說明

對話框會說明需要什麼。你可以選金鑰檔，或直接貼上金鑰（0x 加 64 個十六進位字元），程式會存成金鑰檔，之後記住。

4. 掃描安裝

1打開遊戲的分頁，按 掃描安裝

狀態列下方的進度條會顯示目前步驟，能計數的步驟會顯示數量。

2之後的掃描會沿用結果

遊戲沒更新前，之後掃描都很快。遊戲更新後請重新掃描；GF2 若在掃描後安裝有變，預覽或匯出時會提醒。

5. 搜尋與預覽

1找到模型

在搜尋框（搜尋角色、衣裝或編號…）輸入角色名、衣裝或編號來篩選清單。

2選一列，按 預覽（或雙擊）

第一次預覽會先轉換（幾秒到一分鐘，有自己的進度條）；之後選到這一列就直接從快取顯示。模型載入時會自動置中並框住整個模型。

3操作

左鍵拖曳 旋轉、右鍵拖曳 平移、滾輪 縮放。

4更新後按 重新轉換

預覽會保持第一次轉換的樣子。更新了 Polylode 或遊戲之後，按 重新轉換 重做；新的完成才會取代舊的，失敗時舊的仍保留。

6. 勾選與匯出

1勾選模型

勾選要匯出的列；全選、全不選 只作用在搜尋後看得到的列。

2按 匯出勾選的模型

下方佇列一次處理一個：⏳ 等待、▶ 進行中、✓ 已寫出、✗ 失敗（旁邊的記錄會寫原因）。佇列下的進度條數模型，再下面一條顯示正在寫的那個模型的步驟。 匯出進行中關閉視窗會先詢問。

3到輸出資料夾拿檔案

檔案在 <輸出資料夾>\<遊戲>\<模型編號>\。貼圖都包在檔案裡；旁邊的 .json 記錄骨頭路徑與每個材質的原始數值。

7. 開啟匯出的檔案

格式適合說明
.glb任何 3D 軟體、網頁檢視器只放畫面上看得到的部件，在哪個軟體開都和預覽一樣。
FBXBlender、Unity、Maya 等另外保留隱藏的部件（較低細節層級、可替換部件的其他版本），開啟後是隱藏狀態，需要時再打開。
.blendBlender和 FBX 一樣保留隱藏部件，材質疊層保持真正的分層。
材質照遊戲的畫法寫出：裁切、半透明、眼影與眼睛高光疊層、特效材質（例如終末地角色的翅膀）與發光貼圖。 特效的光在 glTF／FBX 裡寫成「發光」，所以在場景沒有燈光時也看得到。

8. 模型檢視器

1開啟模型

清單列出輸出資料夾裡的模型（最新的在前）。也可以按 開啟檔案…、把檔案拖進視窗，或用 Polylode.exe <檔案> 開啟 （可設成 Windows 的「開啟檔案」程式）。支援 .glb、.gltf、.fbx、.obj。

2檢視

正面、背面、左側、右側、上方 轉到指定視角； 線框、背景深淺與 光 改變畫法。右邊列出 glTF 的內容（網格、頂點、骨頭、形態鍵、各材質的混合方式），並標出用舊規則寫出、建議重新匯出的檔案。

3刪除

刪除… 會把模型、同名的檔案與它的貼圖資料夾移到資源回收筒，可以還原。

4分享

分享到 GitHub Pages… 把顯示中的 .glb 放到你自己的網頁上，給 Discord 用：見 分享到 Discord。

9. 分享到 Discord（透過 GitHub Pages）

Discord 不能顯示 3D 模型，貼上去的 .glb 只是一個下載檔。Polylode 把模型分享成你自己 GitHub 帳號裡 GitHub Pages 網站上的一個網頁： 網頁在任何瀏覽器裡都能轉動模型，網址貼到 Discord 會顯示成帶模型圖片的卡片。不需要另外安裝任何東西：不用 Git，也不用 clone。

1開啟一個 .glb，按 分享到 GitHub Pages…

在模型檢視器裡。它會先說模型會公開在哪個網址，問過你才繼續。

2登入 GitHub（第一次）

瀏覽器會開啟 GitHub 的登入頁，程式顯示一組短代碼（已複製）：輸入代碼並授權 Polylode。它只要求 public_repo（建立與寫入公開倉庫）， 授權只存在這台電腦，並以你的 Windows 使用者加密保存。設定 → GitHub 帳號 → 登出 會把它刪掉；也可以在 GitHub 的 Settings → Applications 撤銷。

3上傳

它會在你的帳號建立公開倉庫 polylode-models（只有第一次），再把 models/<名稱>/：模型、照預覽畫出的 1200×630 卡片圖與網頁， 連同列出所有分享模型的網站首頁，以一個 commit 上傳。每一步都寫在記錄裡。

4開啟 Pages（一次）

如果這個倉庫的 Pages 還沒開啟，訊息會有 開啟 Pages 設定：選 Deploy from a branch、main、 / (root)，按 Save。從程式直接開啟需要存取你所有私人倉庫的權限，程式不會要這個權限。

5把網址貼到 Discord

網址已複製：https://<帳號>.github.io/polylode-models/models/<名稱>/。GitHub Pages 通常一兩分鐘後更新。 在 Discord 會顯示成卡片；點開的網頁可以用滑鼠或手指轉動模型。

姿勢。 終末地角色匯出的 .glb 會帶著遊戲角色介面上擺的姿勢（遊戲裡循環播放的 ui 動作，第一次從安裝解碼，大約半分鐘）。 分享的網頁有 Pose 選單可以切換，卡片圖顯示第一個姿勢。設定 → 姿勢 可以關掉；預覽一律不含姿勢。 少女前線 2 的服裝會帶著戰鬥以外展示用的待機姿勢（宿舍、衣櫃、臥室、結局：遊戲循環播放的動作）； 第一次匯出會為遊戲的動作建一次名稱索引（幾分鐘）。鳴潮的角色會帶著角色介面循環播放的姿勢（CommonAnim/UiAnim：在自己骨架上、結尾回到起點的動作）， 用這個版本建置的讀取器解碼（舊版讀取器會略過）。
已經有自己的 Pages 網站？把 設定 → GitHub Pages 網站資料夾 指到它在本機的 clone，分享就會改成提交到那裡、用 Git 推送。
分享出去的東西都是公開的，連模型檔也是。模型來自遊戲，請自行確認可以分享。只能分享 .glb，最大 100 MB（GitHub 的單檔上限）； 同一個模型再分享一次會換掉它的網頁。本程式自己的資料夾不能當網站。

在 Discord 裡轉動模型（Discord Activity）

Discord 的連結卡片是一張圖。要在 Discord 裡轉動模型，要用 Discord Activity：在 設定 → Discord Activity 填 Discord 應用程式的 Application ID，分享網站的首頁同時就是那個應用程式的 Activity。在語音或文字頻道從 Discord 的 Activity 選單開啟，點一個模型，就能在 Discord 裡轉動、縮放、切換姿勢。

1把應用程式對應到你的網站

在 Discord 開發者平台、你的應用程式：Activities → URL Mappings，根 / 指到 <帳號>.github.io/polylode-models（不要加 https://），儲存。

2開啟 Activities

Activities → Settings → Enable Activities（要先有 URL 對應）；Installation 勾 User Install 與 Guild Install。

3把 ID 交給 Polylode，再分享一次

把 Application ID（General Information）填到 設定 → Discord Activity，再分享任一個模型， 首頁才會照它寫出。

10. 疑難排解

狀況處理
掃描、預覽或匯出前跳出對話框或選檔視窗缺少轉換需要的工具，而且程式在常用位置找不到。鳴潮通常是 AES 金鑰檔：選金鑰檔或貼上金鑰，之後會記住。
記錄出現「「…」還沒有設定」或「「…」不存在」到 設定 修正那個路徑。
沒有寫出 .blend到 設定 指定 Blender 執行檔。
檢視器顯示「量不到這個檔案的大小」讀不到檔案範圍（例如 FBX 7.5），視角放在原點，用滾輪縮放。
預覽和舊的匯出長得不一樣程式更新後轉換規則可能改了：預覽按 重新轉換，匯出檔重新匯出一次。
記錄寫「沒辦法畫出，設為不可見」那個材質無法照遊戲的畫法寫出，程式會把它設為不可見並寫下原因，不會畫成一塊灰白。
分享時出現「git push 失敗」Git 推送不到網站的倉庫：在 Git 登入 GitHub（例如 Git Credential Manager），並確認自己能從那個資料夾推送。
「網站資料夾的 origin 不是 GitHub 倉庫」網站資料夾要是某個 GitHub 倉庫的 clone。
分享的網址沒有卡片，或網頁找不到倉庫沒有開 Pages、免費方案下倉庫是私人的，或 Pages 還沒更新：等一兩分鐘。
其他錯誤下方記錄保留掃描與匯出輸出的每一行，可以從那裡看原因。
